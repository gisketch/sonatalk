The Problem

The agent writes the feature in minutes.

Then I spend the rest of the day reviewing everything it wrote.

Speed stopped being the bottleneck. Trust is the bottleneck.

One Idea

Feedforward steers. Feedback corrects.

Only feedback → it repeats the same mistakes. Only feedforward → you never learn if the rules worked.

My Harness

Sonata — the same two ideas, made concrete

Feedforward

Skills that build

A set of skills the agent runs to take a feature from idea to code — grilling, speccing, ticketing, implementing. The agent can't skip steps.

Feedback

Checks that validate

Quality sensors that fire on every change and feed errors straight back. The agent self-corrects before I read anything.

 github.com/gisketch/sonata — grown feature by feature on real work, not designed in a vacuum.

Sonata · The Feedback Half

Sensors that agents actually listen to

Agents write god-files

300-line limit

My own script, run by the agent itself. Big files degrade both agent context and human review — so they simply aren't allowed to exist.

Agents over-engineer

scc — complexity

Counts lines and complexity across the codebase. When a "small feature" balloons, the numbers say so before I do.

Agents leave orphans

skylos — dead code

Agents love leaving unused functions and imports behind after refactors. Dead code detection hunts the ghosts.

These are examples, not a prescription — the pattern is: every check speaks in errors the agent can act on.

Documentation the agent actually reads

Architecture notes

How the system fits together — so the agent extends the design instead of inventing a parallel one.

Conventions & how-tos

How we name, structure, test, and ship here. Loaded before generation — feedback I never have to type twice.

Kept alive by the flow

Docs update as part of every feature — not a wiki that rots, a context system that compounds.

Documentation stopped being for humans only. It's executable context now.

Your Turn

Build your own. Start tiny.

1 · Write one rule down

Put a single convention in AGENTS.md — the thing you keep correcting. Ten minutes, today.

2 · Wire one sensor

A linter, a test, a check — with error messages the agent can read and act on.

3 · Repeat forever

Every mistake that happens twice becomes a new guide or sensor. That's the whole practice.

The model isn’t the moat.
The harness is.
